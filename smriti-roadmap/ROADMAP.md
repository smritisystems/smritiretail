# SMRITI Roadmap

Status: Draft governance scaffold for the frozen platform baseline

## Purpose

This repository is the single planning home for milestone sequencing, release scope, and lifecycle decisions. It does not redefine architecture, contracts, or implementation details.

## Scope

- Milestones and release sequencing
- Planned platform capabilities and rollout order
- Frozen and deprecated feature status
- Release-to-ADR traceability

## Current Direction

1. Architecture baseline frozen
2. Contracts and design system frozen
3. SDK and platform kernel implementation progressing
4. Platform capabilities to be delivered in sequenced milestones
