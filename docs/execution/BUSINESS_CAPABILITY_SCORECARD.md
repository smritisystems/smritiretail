# Business Capability Scorecard

**Purpose:** Track progress at the business capability level so management can see how each capability pack is maturing across its documents.

## Structure

Each capability is scored from the readiness of its constituent business documents.

```text
Sales Capability
───────────────
Quotation .......... 100%
Sales Order ........ 100%
Delivery Challan ... 100%
Invoice ............ 100%
Return ............. 100%

Overall Capability = 100%
```

## Scoring Method

A capability score is derived from the average readiness of its documents.

```text
Overall Capability = Average of all document readiness values
```

## Example

```text
Sales Capability
───────────────
Quotation .......... 100%
Sales Order ........ 70%
Delivery Challan ... 20%
Invoice ............ 0%
Return ............. 0%

Overall Capability = 38%
```

## Execution Use

Use this scorecard together with:
- the milestone dashboard
- the document readiness model
- the business document registry

This provides a clear hierarchy of execution visibility:

```text
Project
    ↓
Capability
    ↓
Document
    ↓
Readiness
```
