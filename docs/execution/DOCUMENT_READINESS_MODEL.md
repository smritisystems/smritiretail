# Business Document Readiness Model

**Purpose:** Provide a structured readiness score for each business document so delivery can be tracked at the document level, not only at the milestone level.

## Readiness Areas

Each document is evaluated across the following areas:

- Backend
- UI
- Workflow
- Finance
- Inventory
- Print
- Reports
- Dashboard
- API
- Tests
- UAT
- Documentation

## Weighting

| Area | Weight |
|---|---:|
| Backend | 15% |
| UI | 15% |
| Workflow | 10% |
| Finance | 10% |
| Inventory | 10% |
| Print | 5% |
| Reports | 10% |
| Dashboard | 5% |
| API | 10% |
| Tests | 5% |
| Documentation | 5% |
| UAT | 5% |

## Readiness Rule

A document reaches 100% readiness only when every required area is complete.

## Suggested Score Format

```text
Document: Sales Quotation
Readiness: 0% / 100%
- Backend: Pending
- UI: Pending
- Workflow: Pending
- Finance: Pending
- Inventory: Pending
- Print: Pending
- Reports: Pending
- Dashboard: Pending
- API: Pending
- Tests: Pending
- Documentation: Pending
- UAT: Pending
```

## Execution Use

Use this model in addition to milestone tracking to provide fine-grained visibility for RC2 delivery.
