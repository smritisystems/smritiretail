## Governance Rule

No new milestone begins until the current milestone reaches 100% according to its Definition of Done, unless an explicitly approved cross-cutting dependency requires parallel work.

Execution should be tracked by milestone, by business document, and by business capability. Use the document readiness model and capability scorecard for fine-grained visibility.
