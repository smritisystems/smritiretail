# Sales Quotation SQ-001 Requirements

## Objective
Deliver a complete Sales Quotation document that can be created, validated, approved if configured, printed, and reported.

## Functional Scope
- Customer selection
- Item selection
- Pricing and discount
- Tax calculation
- Validation rules
- Workflow and approval
- Print and PDF generation
- Reports and dashboard metrics
- REST API support
- Audit trail and notifications

## Acceptance Criteria
- A quotation can be created from master data
- Pricing, discount, and tax are calculated consistently
- Validation rules prevent invalid entry
- The workflow can move through configured states
- The document can be printed and exported
- The document is available through APIs
- Tests cover the core business flow
