# ADR-0011: Notification Framework

## Status

Accepted

## Decision

All system notifications, alerts, reminders, and in-app toasts in SMRITI Retail OS shall be implemented through the shared Notification Framework.

## Consequences

- Consistent notification behavior
- Reusable event-driven delivery
- Easier integration with workflow and audit events
