# ADR-0012: Offline Synchronization Framework

## Status

Accepted

## Decision

All offline persistence, queueing, and synchronization behavior in SMRITI Retail OS shall be implemented through the shared Offline Synchronization Framework.

## Consequences

- Consistent offline-first experience
- Reusable sync and conflict handling
- Better support for mobile and remote users
