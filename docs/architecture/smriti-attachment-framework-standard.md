# SMRITI Universal Document & Media Attachment Standard

## Purpose

Every master record, transaction, workflow, and business document in SMRITI Retail OS shall support standardized attachment handling.

## Requirements

- Attachments must be available for masters and transactions through a shared framework.
- Support for images, documents, media, archives, and custom file types.
- Inline preview, versioning, permissions, search, audit trail, and scalable storage providers.
- Mobile and offline upload support.
- Modules must use the shared attachment framework and not implement their own attachment logic.
