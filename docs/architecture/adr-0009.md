# ADR-0009: SMRITI Universal Document & Media Attachment Framework (SDAF)

## Status

Accepted

## Decision

All attachment handling in SMRITI Retail OS shall be implemented through the shared Attachment Framework.

## Consequences

- Consistent attachment experience across modules
- Reusable versioning, preview, and audit capabilities
- Easier security and storage governance
- Better support for mobile, OCR, and offline workflows
