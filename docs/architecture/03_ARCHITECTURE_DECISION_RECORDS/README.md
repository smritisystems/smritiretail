# Architecture Decision Records

This folder contains Architecture Decision Records (ADRs) for changes to the frozen SMRITI platform layer.

## Rule

No platform-level change should be made without an ADR.

## ADR Template

Use the following structure for new ADRs:

1. Title
2. Status
3. Context
4. Decision
5. Consequences
6. Compatibility impact
7. Rollout plan
