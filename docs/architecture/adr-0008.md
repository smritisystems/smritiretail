# ADR-0008: SMRITI Workspace Persistence Framework (SWPF)

## Status

Accepted

## Decision

All workspace persistence logic in SMRITI Retail OS shall be implemented through the shared Workspace Persistence Framework.

## Consequences

- Zero data loss on refresh for supported workflows
- Consistent recovery behavior across modules
- Centralized maintenance and governance
- Better offline and multi-tab support
- Easier certification for new modules
