# ADR-0013: Workflow & Approval Framework

## Status

Accepted

## Decision

All workflow and approval logic in SMRITI Retail OS shall be implemented through the shared Workflow & Approval Framework.

## Consequences

- Consistent approval lifecycle
- Reusable decision and audit integration
- Easier business-process orchestration
