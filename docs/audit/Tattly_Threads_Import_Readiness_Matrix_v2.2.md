## 3. High-Risk Ingestion Blocker Registry (Detail on BLOCKED Rows)

### Cluster A: Missing Mandatory Heel & Upper in Brand KORA (266 Rows)
- **Affected Styles:** `1383`, `2130`, `1057`, `2097`, `2006` (Rows 578 to 843).
- **Root Cause:** Ingestion contract Standard v2.2 enforces `HEEL_TYPE` and `UPPER_MATERIAL` as mandatory (`BLOCK`). These cells are completely empty in the customer sheet.
- **Action Mandate:** Merchant must populate valid heel types and upper materials before import.

### Cluster B: Style 2006 CREAM Dual-MRP Variant Collision (14 Rows)
- **Affected Rows:** Rows 662–668 (MRP ₹1,299) vs Rows 795–801 (MRP ₹1,499).
- **Root Cause:** Two distinct production runs share identical variant SKU candidates (`2006-CREAM-36` through `42`) with different barcodes and conflicting prices.
- **Architectural Invariant:** SMRITI requires settling whether MRP participates in variant identity or is a versioned commercial attribute. Batch 2 must be versioned (e.g. `2006-V2`) or governed via PriceBook matrices.

### Cluster C: Ambiguous Upper Material 'MATERIAL' (80 Rows)
- **Affected Styles:** `SND-01-C`, `SND-02-C`, `SND-03-C`, `SND-04-C` (Rows 178 to 273).
- **Root Cause:** Generic placeholder string `'MATERIAL'` does not define leather, synthetic, or textile composition. Ingestion cannot proceed without statutory HSN risk.
- **Action Mandate:** Merchant must supply the exact material composition.

### Cluster D: Missing Vendor Code (16 Rows)
- **Affected Rows:** Rows 662–668 and 795–801 (Style `2006`), plus 2 rows under Style `2130`.
- **Root Cause:** Rule `IM-007` requires all items to be qualified by an approved supplier code.
- **Action Mandate:** Supply chain operations must provide vendor attribution.
