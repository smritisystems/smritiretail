# Walkthrough: Footwear Purchase Order Print Template with Euro Sizing & Currency Defaults and Persistent SMRITI Retail OS Branding

## 1. Purpose
To deliver an enterprise-grade Footwear Purchase Order (A4) print template with:
1. **Euro Sizing Standard (EU 40–45)** as the default sizing scale across matrix runs and carton assortment ratios.
2. **Euro Billing Currency (€ / EUR)** as the primary default currency with dual domestic INR conversion references.
3. **Shoe Profile Thumbnail Images** integrated with dynamic user customizer controls (`printImage` toggle).
4. **Mandatory SMRITI Retail OS Branding** permanently anchored in the running footer across all document types (Footwear PO, Standard Tax Invoice, GRN, Thermal Receipts).

## 5. Architecture Decisions
- **Euro Scale Primacy**: In footwear manufacturing and international wholesale, Continental European sizing (EU 39–46 / EU 40–45) serves as the primary technical specification. UK and US sizes are rendered as subordinate conversions directly in the column subheaders.
- **Packaging Assortment Ratio**: 1 Master Carton = 12 Pairs with ratio `1 : 2 : 3 : 3 : 2 : 1` across sizes `EU 40, EU 41, EU 42, EU 43, EU 44, EU 45`.
- **Dual Currency FOB/Domestic Settlement**: The template displays primary pricing in Euros (`€ 21.00`, `€ 14.20`, `€ 36.40`) with automated cross-border reverse charge (0.0% export VAT) and domestic benchmark conversion at fixed FX reference rates (e.g. 1 EUR = ₹ 88.20).
- **Mandatory Footer Branding**: Every printable document generated by SMRITI Retail OS carries an unalterable, cryptographically referenced footer bar declaring:
  `[SMRITI] SMRITI Retail OS | Universal Enterprise Procurement Engine • Audit Ref: SM-FWPO-EUR-2026 • smritibooks.com • Document Integrity Verified`.

---

## 6. Design Rationale
- High-contrast indigo headers (`#1e1b4b`) distinguish footwear orders from standard sales invoices.
- Dedicated technical specification sub-grid per line item details Upper Material, Outsole, Lining, and Insole, conforming to SATRA quality pull test norms (min 4.0 N/mm per SATRA TM411).
- Dynamic CSS print containment: The print layout utilizes `.print-only-container` during `@media print` while remaining 100% visible on screen during interactive modal inspection.
