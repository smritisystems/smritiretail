# 3. Item Master Registration

## Goal

Create a saleable stock item with the correct name, article/style, category, tax, and physical variant details.

## Steps

```mermaid
flowchart LR
  O[Open Article / Design Master] --> N[Start a new item]
  N --> I[Enter identity and product name]
  I --> D[Enter design and variant details]
  D --> T[Check tax and barcode]
  T --> S[Save item]
  S --> V[Find it again and verify]
```

1. Open the **SMRITI Launchpad** and choose **Article / Design Master** (also called Item Master in some menus).
2. Search by product name, SKU, barcode, and article/style code. If the item already exists, open it instead of creating a duplicate.
3. Start a new item using the screen's **New/Add** action.
4. Enter the **Product Name**. It is required.
5. Select the correct product type, category, and sub-category from the governed lists. Follow every field marked with `*`.
6. Enter or select the **Article / Style Code**. Use the approved article from the Article Registration step.
7. Enter the physical details, such as colour and size. Select the correct size group and size system when required.
8. Enter the correct HSN and GST rate. Ask the trainer if you are unsure; do not guess a tax rate.
9. Scan or enter the manufacturer's barcode if one exists. Do not make up a barcode. If the system generates SKU/barcode values, use those values and do not overwrite system-controlled identifiers.
10. Enter MRP, selling price, and cost only from approved price information.
11. Review all required fields and save using the screen's save action.
12. Search for the item again. Check its name, article code, variant, tax, SKU, and barcode.

## Check Before You Finish

- The item is linked to the correct article/style.
- Size and colour describe the physical item being stocked.
- HSN, GST, MRP, selling price, and cost match approved data.
- The item can be found by its code or barcode.

## Practice Task

Find an existing practice item and read its SKU, article, colour, size, and tax details. Create a new item only when the trainer gives you approved practice data.
