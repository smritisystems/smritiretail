# 1. Vendor Registration

## Goal

Add one approved supplier so staff can select that supplier on a Purchase Order.

## Who Can Do This?

The launchpad lists Vendor 360 for `MANAGER` and `SYSADMIN` users. If you cannot see it, ask the trainer or system administrator to check your access.

## Steps

```mermaid
flowchart LR
  O[Open Vendor 360] --> S[Search first]
  S --> N[Click New]
  N --> F[Enter vendor details]
  F --> C[Create Vendor]
  C --> D[Review vendor record]
  D --> T[Complete other tabs and save]
```

1. Open the **SMRITI Launchpad**.
2. Open **Vendor 360 Workspace**.
3. Search by vendor name, code, or GSTIN. Do this before creating anything. If the vendor is already listed, open that record instead of making a duplicate.
4. If it is a new vendor, click **New**.
5. Select the **Vendor Code** from the active system list. Do not type a made-up code.
6. Enter the **Legal Company Name**. This field is required.
7. Enter the trade/display name if it is different.
8. Enter the vendor's verified GSTIN, PAN, contact number, email, city, state, and PIN code when available.
9. Choose the correct supplier type and payment terms. Confirm these with the trainer or approved vendor paperwork.
10. Click **Create Vendor**.
11. Open the vendor record. Review the identity and status.
12. Complete the needed **Addresses**, **Contacts**, **Commercial**, and **Banking** tabs. Enter bank information only from approved documents and only if your role permits it.
13. Click **Edit Vendor** before changing a saved record. Click **Save Changes** when finished.
14. Search for the vendor again and confirm that one correct record appears.

## Check Before You Finish

- The code and legal name match the approved vendor documents.
- The GSTIN belongs to this vendor and has no typing errors.
- Payment terms and supplier type were approved.
- The vendor is active and can be selected in Purchase Studio.

## Practice Task

Find an existing practice vendor, read its code and GSTIN aloud, and explain which fields must be checked before using it on a PO. Do not create a real vendor during practice unless the trainer assigns one.
