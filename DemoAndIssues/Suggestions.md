# Feature Suggestions

## Missing Features
- Clearer guidance for first-time users when tenant assignment is required
- A built-in demo mode that allows evaluation without manual tenant configuration

## UI Improvements
- Improve the onboarding message with a direct “Next Step” or “How to Continue” action
- Provide a more visual module availability state for users

## Workflow Improvements
- Offer a guided demo flow that opens common retail workflows without full tenant setup
- Simplify the path from login to first transaction

## Performance Suggestions
- Reduce loading delays when switching between business domains
- Add progress indicators for data fetches and workspace initialization

## Ease of Use
- Provide contextual help and sample workflow prompts for sales and POS users
- Add role-based walkthroughs for retail owners and managers

## SAP-style Improvements
- Stronger role-based navigation control
- Better operational status panels for branch and company visibility

## Microsoft Fluent Improvements
- More consistent spacing, card states, and empty-state visuals
- Better affordances for action buttons and navigation hints
