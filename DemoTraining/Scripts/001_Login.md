# Login Demo Script

## Introduction
Welcome to the login experience. In this session, we will learn how to sign in safely and access the main workspace.

## Purpose
The login screen provides secure access to the system for different roles such as admin, manager, and cashier.

## Business Scenario
A user needs to access the ERP system to begin daily operations.

## Navigation
1. Open the application.
2. Enter the username and password.
3. Select the sign-in option.
4. Review the workspace landing page.

## Step-by-Step Demonstration
- Enter the correct credentials.
- Review the password field behavior.
- Sign in and wait for the workspace to load.
- Observe the landing page and role-based layout.

## Tips
- Use the correct role-based account.
- Keep passwords secure.
- Confirm that the account is assigned to the right company or branch if required.

## Common Mistakes
- Entering the wrong password.
- Using the wrong role account.
- Ignoring permission messages.

## Summary
The login module is the first impression of the system and should feel simple, secure, and dependable.
