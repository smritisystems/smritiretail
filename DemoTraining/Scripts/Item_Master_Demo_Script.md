# Item Master Demo Script

## Opening
Welcome to the Item Master experience. In this walkthrough, we will see how a retail team can create, manage, and print barcode labels for products using the browser.

## Step 1 – Open Item Master
- Open the dashboard.
- Navigate to Inventory.
- Open Item Master.
- Show the product workspace and the available actions.

## Step 2 – Bulk Import
- Open the bulk import view.
- Explain that this is the fastest way to add many products at once.
- Show the grid for paste-based data entry.
- Highlight the option to use copy-paste from Excel or Google Sheets.

## Step 3 – Paste Product Data
- Paste the footwear item data into the import grid.
- Show the product rows appearing in the sheet.
- Explain that the system can process multiple variants and barcodes in one batch.

## Step 4 – Generate SKUs
- Use the SKU generation option.
- Show the system processing the rows.
- Explain that this helps standardize product codes for retail operations.

## Step 5 – Validate the Sheet
- Review the validation results.
- Explain that the system checks the rows before committing them.
- If errors are shown, explain how the user would review and fix them.

## Step 6 – Commit to the System
- Commit the validated records.
- Explain that the product master now contains the uploaded items.

## Step 7 – Print Barcode Labels
- Select the products or variants.
- Open the print label workflow.
- Choose a label template.
- Review the preview.
- Generate the print output.
