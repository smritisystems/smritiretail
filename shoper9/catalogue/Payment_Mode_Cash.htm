Payment Mode – Cash

Currency Name: Enter description or name of the currency.

Local Currency: Select to set the currency as local currency. Only one currency can be catalogued as local currency. Once a currency is set as local currency, for subsequent entries the check box will be disabled.

Conversion Rate: The rate at which the currency will be converted to the local currency. Thus, for the local currency this value is always 1.

Rate as On: Date and time at which the conversion rate is published.

Rate Change Frequency: The frequency at which the conversion rates are expected to get changed is specified here in terms of hours or days.

Allowed In PO: Select if this currency is allowed to be used in Purchase Orders.

Allow In Tender: Select if this currency is allowed to be used in Tenders.

Allowed in Payouts: Select if this currency is allowed to be used in payments. Disabling this will enforce returning balance in local currency.
