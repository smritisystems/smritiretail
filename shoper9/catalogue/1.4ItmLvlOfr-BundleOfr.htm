Offer on Item Combinations

This promotion type helps you to define schemes where buy a combination of different items and get selected items free. Here, the definition is based on item combinations.

The details to be captured can be divided into two parts, namely, Buy Items and Offer Details.

Buy Items

This section allows you to select the items to be bought to avail offer.

The Buy Items section is as shown.

This promotion type cannot be applied on all items, since the definition is based on item combinations.

Configure: Click to configure the options for item selection. Click here for more information.

The Buy Items grid displays the item classification columns as configured. On pressing F2 in any item classification column, the corresponding browse window is displayed with the list of catalogued values to select from.

Note: In the Buy Items grid:

   · You can press F2 anywhere in the grid, irrespective of the order in which the item classification columns are present, to select values of any attribute.

   · You have the flexibility to select either one or multiple attributes in a row, to specify the required items.

   · If Stock No. of an item is selected, the remaining item classification columns for that stock number will be filled automatically.

As promo is defined on item combinations, you need to specify the item combination by grouping the items into different sets. Select the first set of items in the grid.

Quantity: Specify the quantity for the first set of items to avail the offer.

Set No.: Auto assigned depending on the condition selected in the next column.

Condition: Select And or Or to specify the criteria. Last row will always have End. When you select And, the offer is applicable if the buyer picks the items in both the current row and the next row. Selecting Or indicates the offer is applicable if the buyer picks the item either in the current row or the next row.

If the condition selected is And the item in the current row and next row will be in two different sets and the sets will be numbered accordingly. If the selection is Or, the items will be in the same set and both rows will be assigned the same set number.

In case you are selecting Or, the quantity for both item combinations in the set will remain the same and hence the quantity column in the next row will be non editable.

Notice that set numbers are assigned to the rows based on your selection in Condition.

Free Items

This section allows you to select the items to be given free.

Item selection can be done either by selecting the values for attributes displayed in the grid or by loading from a CSV file.

Selecting values for attributes:

Configure: Click to configure the options for item selection. Click here for more information.

The Free Items grid displays the item classification columns as configured. On pressing F2 in any item classification column, the corresponding browse window is displayed with the list of catalogued values to select from.

Note: In the Free Items grid:

   · You can press F2 anywhere in the grid, irrespective of the order in which the item classification columns are present, to select values of any attribute.

   · You have the flexibility to select either one or multiple attributes in a row, to specify the required items.

   · If Stock No. of an item is selected, the remaining item classification columns for that stock number will be filled automatically.

The item quantity of the items that will be given as free needs to be specified.

Quantity: In the first row, enter the quantity of the selected items to be given free. The same value is copied to all other rows.

Loading from a CSV file:

Note: The Load option will be available only if you have selected the option Load Item Details from File under Configure.

Load: Click to load the item details from a CSV file, if available. Click here for more information.

Tip: To make loading faster, configure the item classifications according to the order of data values in the CSV file.

Applied on: You may configure the default behaviour for selecting lowest/highest priced item to be given as free item.

Select Lowest priced item, if the free item is to be the lowest priced item among the items bought.

Select Highest priced item, if the free item is to be the highest priced item among the items bought.
