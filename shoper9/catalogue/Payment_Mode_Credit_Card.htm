Payment Mode – Credit Card

Issue Agency: Enter the name of the agency that has issued the Credit Card. Press F2 to select from the list of agencies catalogued earlier. If the agency is not in the list then press Insert key to open the Agency Catalogue window and catalogue the new agency details.

Number of Components: Shoper accepts information like

  • Credit Card number while accepting Credit Card as the mode of payment in billing process

  • Batch number during credit card submission process

  • Cheque number during realisation process

for accounting the amount received from the credit card servicing agency. The captions to be displayed for accepting these components in various screens and the type of field to be captured for these components are to be provided in the Submission Details tab.

The number of fields and captions in the credit card Billing, Submission and Realisation will vary based on the payment mode catalogue settings. There can be totally 10 components in the payment mode.

Billing accepts various captions catalogued in the payment mode. This caption will be displayed in the Billing screen for credit card.

Submission accepts various captions catalogued in the payment mode. This caption will be displayed in the Submission screen for credit card.

Realisation accepts various captions catalogued in the payment mode. This caption will be displayed in the Realisation screen for credit card.

Billing: Enter the number of additional fields to be captured during billing process.

Submission: Enter the number of additional fields to be captured during submission process.

Realization: Enter the number of additional fields to be captured during realisation process.

Submission: Select if the credit card used in billing be allowed for submission to the selected agency.

Submission Online: Select to identify the agencies that allow online authorisation.

Commission Rate: The commission rate charged by the agency when the credit card is submitted for realisation.

Next: To move to the Submission Details tab

The Submission Details tab is displayed.

Caption: Enter relevant captions to be applied at each point.

Type: Select the type of value that can be entered at each point.

Applied At: The point at which the chosen values will be applied.

Ok: To save the values entered

Cancel: To cancel the cataloguing activity chosen
