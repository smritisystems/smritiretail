Payment Mode – Add

The Mode of Payment Catalogue is as shown.

 

Mode of Payment: Select the mode of payment from the list. Various modes possible are Cash (local or foreign currency), Credit Card, Discount Card, Gift Coupons, Advance Receipt, Cheques and Credit Note.

If mode of payment selected is Advance Receipts, Cheques or Credit Note, you just need to specify if the selected payment mode can be used at POS.

If you have selected Cash, Credit Card, Discount Card or Gift Coupon, certain fields corresponding to the aforementioned payment modes are displayed. A common field for these payment modes is Payment Code. Each of these fields is explained in detail below.

Payment Code: The code can be up to 16 digits long. Though there is a description that is associated with the code, most reports list only the code. Hence you need to give a meaningful code.

Enable in POS Trn: Select to indicate that the instrument can be allowed at POS.

Cancel: To undo the values chosen. Click this button a second time to cancel the functionality chosen.
