Payment Mode

The Payment Mode is used by sales and cash transaction functions of Shoper 9 POS and Shoper 9 Distributor. This catalogue stores currencies that are allowed at the POS.

How to reach: Catalogue > Payment Mode

The Mode of Payment Catalogue window is displayed. In this window you can execute the following functions.

Add: Click to add a mode of payment. Click here for more information.

Edit: Click to edit an existing mode of payment. Select the Mode of Payment and enter the Payment Code to display the catalogued details. Make necessary changes as explained in Add option. Click Ok to confirm modification.

Delete: Click to delete an existing mode of payment. Select the Mode of Payment and enter the Payment Code to display the catalogued details. Click Ok to delete the selected Payment Code.

Exit: To quit the Retail Tenders option.
