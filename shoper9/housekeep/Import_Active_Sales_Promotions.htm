Import Active Sales Promotions  

This option can be used when you need to activate sales promotions for the newly added items, after the day open, coming under the purview of sales promotions catalogued earlier.   

How to reach: Housekeeping > Data Import > Active Sales Promotions

The Extract Active Sales Promotions window is as shown.

 

For:Displays the date of extraction.  

Advanced: Click to provide Delete and extract all active sales promotions field option

Delete and extract all active sales promotions: Select to delete the entire existing sales promotions scheme and repopulate with the active schemes.

Note:

If you do not select Advanced option and click Ok:

   · The discrepancies existing in the Sales Promotion schemes are identified and updated.

   · The un-processed active sales promo schemes (probably new) are extracted from the current item master.

   · The new items probably created after sales promo creation are processed and included in the existing active

     sales promo schemes if their item classifications are matching.

 

Ok: To start extraction for the date mentioned

Exit: To quit the option
