Support Centre using Licensed Tally.ERP 9

Shoper 9 users, who have a licensed version of Tally.ERP 9 installed on the same network have the option to use their Tally.ERP 9 to access the Support Centre using Shoper 9 Account ID from the same menu option.

Configure the Support.ini file available in Shoper 9 application folder. Edit the file and enter the path of the directory where Tally.ERP 9 is installed against TallyAppPath, for e.g., TallyAppPath=C:\Tally.ERP9 and save the file.

With the new configuration to Support.ini file, open Support Centre from Shoper 9 menu option.

The licensed Tally.ERP 9 is opened and Support Centre login screen is displayed. The user can enter account id (tally.net user id) and password to access the Support centre for Shoper 9 Account ID.
