Invoicing

The Invoice option in the main menu leads to a window that allows all operations related to invoicing. These include generation of a new invoice, cancellation of an invoice, recording sales returns, reprinting an invoice or sales return document, and change invoice prefix for cash and credit transactions.

How to reach: Sales > Invoice

 

Note: The options Return and Cancellation also open the same window.

The Invoice window has the following components as shown.

Tool Button

Shortcut Keys

Functionality

 

Alt+1

Create a new invoice

Alt+2

Void/ cancel an invoice generated earlier

Alt+3

Record sales returns with reference to an earlier sale (Invoice/ Cash Memo)

Alt+5

Record sales returns without reference to an earlier sale (i.e., when the customer does not have the copy of invoice and when it is not possible to trace out the invoice through which the sale was made earlier)

Alt+6

 Reprint an invoice or sales return document

 

—

Change the bill prefix for cash and credit transactions

 

Note:

· Only one among the New Invoice, Return and Return without reference can be used at a time.

· Alter Prefix can be used only when no other functions are in use.

All functions are not applicable in all transactions. See the chart for the list of functions and their applicability.

Transaction Prefixes

The prefixes to be used for invoicing (here, Cash Transactions and Credit Transactions) under a Product and Service Bill as defined in the Bill Prefix are displayed. If you carry out invoicing without defining the bill prefixes, you will get the appropriate messages.
