Reprint Invoice/ Sales Return

Invoices or Sales Returns can be reprinted, if they are lost or damaged while printing earlier.

The Re-Print Invoice/Return window is as shown.

Document Type:  Select the document type, i.e., Invoice or Returns from the drop down list.

Customer Details: Press F2 and browse for the customer details or enter the details.

Single Document: Select if a single document is to be reprinted.

Range of Documents: Select if many documents are to be reprinted.   

Document Prefix: Enter the Document Prefix of the Invoice/ Sales Return to be reprinted.       

Doc. No. From and To: Enter the document number of the Invoice/ Sales Return to be reprinted. Enter the document number of the first transaction in From field and document number of the last transaction in To field, if a range of documents is to be reprinted.

Document Prefix: The document prefix of the Invoice/ Sales Return, which is printing currently, is displayed in this field. This is applicable only if you have a range of documents to be printed.

Document No: The document number of the Invoice/ Sales Return, which is printing currently, is displayed in this field. This is applicable only if you have a range of documents to be printed.

Sales Staff: The code of the sales staff who prepared the Invoice/ Sales Return, which is printing currently, is displayed in this field. This is applicable only if you have a range of documents to be printed.

Document Date: The document date (current Shoper date) is displayed in this field.

Doc. Remarks: The remarks, if any, is displayed in this field.

Item Details: The item details of the selected document are displayed in this grid.  

Document Net Values: Displays the net values of the entered document number, i.e., Add-ons, Deductions, Discounts, Tax, Quantity or number of items present in the transaction and the net value of the document (Invoice/ Sales Return), in the respective fields.

Print: To print the document

Cancel: To cancel the entry
