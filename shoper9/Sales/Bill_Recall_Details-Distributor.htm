Recall

The Recall option allows you to recall (configurable) transaction types (expected transactions) like Sales Orders, Sales DC, Approval Issue DC and Suspended Invoices at any stage of an invoicing process. On recalling any of these transaction types, you get the items, which are entered previously in the respective transaction types. In a single invoicing process, you can recall any or all the transaction types available for that particular invoice type (i.e., Product invoicing or Service invoicing). Once you recall a document in a terminal, the same document will not be available for recall in any other terminals. Customer validation can be done before recalling a transaction slip, if configured.

On clicking Recall button from the Invoice window, Recall Details is displayed.

Transaction Type: Select the type of transaction from the drop down list.

Doc No Prefix: The document prefix used for the selected Transaction Type is displayed by default. You can edit this value, if required.

Document No: Enter the document number. Alternatively, press F2 and the Document Search window for the selected Transaction Type pops up. You can browse for the document number in this window.

 

Submit: To submit the recall details entered to proceed with the invoicing.

Cancel: To exit from the Recall Details window. You can also press Esc to exit.

 

Notes:

    · You may delete items from the document that is recalled, if configured.

    · You may suspend an invoice even after recalling any document. The suspended invoice is available for recall later.

When you delete any items from a document that is recalled, or suspend an invoice after recalling any document, the status of the respective document varies according to the type of the transaction. The possible scenarios are explained.

Sales Order/ Sales DC/ Approval Issue DC

After recalling a Sales Order, Sales DC or Approval Issue DC, if you perform partial deletion, i.e., if you delete one or more items from the recalled transaction type, and invoiced for the rest of the items, then the status of the Sales Order, Sales DC or Approval Issue DC will still be enabled (opened). Here, the Sales Order, Sales DC or Approval Issue DC can be recalled till all the items get invoiced.

Suspension

After recalling a Sales Order, Sales DC or Approval Issue DC, if you suspend the invoice, then the status of the respective transaction type is disabled (closed). However, if you delete this suspended invoice later, then the respective transaction type will be available for recalling it again.
