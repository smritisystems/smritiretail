Reprint Approval Issue DC

Approval Issue DC generated earlier can be reprinted using this option. The reprinting of an Approval Issue DC is required, if it is lost or damaged while printing earlier.

The Re-Print - APPROVAL ISSUE DC window is as shown.

Slip Details

Slip Number Prefix: Enter the prefix of the Approval Issue DC to be reprinted.

Slip Number: Enter the document number of the Approval Issue DC to be reprinted.

Print: To print the selected Approval Issue DC

Exit: To exit the Re-Print - APPROVAL ISSUE DC window without printing the details. You can also press Esc to exit from this window.
