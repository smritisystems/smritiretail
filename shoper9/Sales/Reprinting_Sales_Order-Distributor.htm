Reprint Sales Order

Sales Order generated earlier can be reprinted using this option. The reprinting of a Sales Order is required, if it is lost or damaged while printing earlier.

The Re-Print - SALES ORDER window is as shown.

Slip Details

Slip Number Prefix: Enter the prefix of the Sales Order to be reprinted.

Slip Number: Enter the document number of the Sales Order to be reprinted.

Print: To print the selected sales order

Exit: To exit the Re-print - SALES ORDER window without printing the details. You can also press Esc to exit from this window.
