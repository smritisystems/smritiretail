AddOns and Deductions

The AddOns And Deductions grid pops up beneath the Item Details grid when you press Ctrl+4 from the Invoice window.

Note: If fixed add-ons or deductions are catalogued under Sales Factors, then the same are applied by default and can be viewed by pressing Ctrl+4. The add-ons or deductions can be altered as per the requirement, during invoicing, if they are catalogued as Variable under Sales Factors. Click here to know how to catalogue Add-ons and Deductions.

AddOns

Add-on is an extra amount, which is added to the total sales value during invoicing. The add-on details grid displays the add-on values for that particular invoice. You can add any number of Add-ons, if catalogued, in an invoice.

Type: Select the type (Add-on) from the drop down list.

Code: Select the applicable Add-ons code from the drop down list.

Press Tab and the rest of the details of the grid are populated.

Fixed/Variable: This field indicates whether the selected Add-on is Fixed (F) or Variable (V).

Rate/Amount: This field indicates whether the selected Add-on is applied as a Rate (R) or an Amount (A).

Rate: The rate is displayed. The rate can be changed, if the selected code is of the type Variable (V) and Rate (R).

Amount: The amount is displayed. The amount can be changed, if the selected code is of the type Variable (V) and Amount (A).

The total value of Add-ons is displayed as Addon–Gen at the bottom right corner of the Invoice window.

Note: In the given grid, position of Addon-Gen indicates whether tax is calculated on the add-on value.

      1. Above Sales Tax — The add-on value is considered for tax.

      2. Below Sales Tax — The add-on value is not considered for tax.

Addon-Gen: The total value of add-ons is displayed.

Add Items: To enter more items into Item Details grid.

Press Esc to come out of the AddOns And Deductions pop up.

The AddOns And Deductions grid with a fixed Add-on applied as Rate is displayed.

Deductions

Deduction is an amount, which is deducted from the total sales value during invoicing. The deduction details grid displays the deduction values for that particular invoice. You can add any number of deductions, if catalogued, in an invoice.

Type: Select the type (Deduction) from the list.

Code: Select the applicable Deductions code from the list.

Press Tab and the rest of the details of the grid are populated.

Fixed/Variable: This field indicates whether the selected Deduction is Fixed (F) or Variable (V).

Rate/Amount: This filed indicates whether the selected Deduction is applied as a Rate (R) or an Amount (A).

Rate: The rate is displayed. The rate can be changed, if the selected code is of the type Variable (V) and Rate (R).

Amount: The amount is displayed. The amount can be changed, if the selected code is of the type Variable (V) and Amount (A).

The total value of Deductions is displayed as Dedns–Gen at the bottom right corner of the Invoice window.

Note: In the given grid, position of Dedns-Gen indicates whether the deduction amount is considered for tax calculation.

      1. Above Sales Tax — The deduction amount is considered for tax calculation.

      2. Below Sales Tax — The deduction amount is not considered for tax calculation.

Dedns-Gen: The total value of deductions is displayed.

Add Items: To enter more items into Item Details grid.

Press Esc to come out of the AddOns And Deductions pop up.

The AddOns And Deductions grid with a fixed Deduction applied as Amount is displayed.

Transporter Details

The details of the transporter carrying the items from the distributor are recorded in Transporter Details. Select the Transporter Details Tab and enter the relevant details.

Tran.Mode: Select the mode of transportation of the items, from the list. The list contains the transportation modes that are catalogued.

Tran.Code: Select the transporter code, from the list. The list contains the transporter codes that are catalogued.

Tran. Name: The name of the transporter is displayed.

L.R. Details

The lorry receipt details are recorded in this section.

L.R.No: Enter the LR number for the items.

L.R.Date: Select the date on which the LR details are recorded.

Payment Details

The details like payment mode, bank code, credit days and transit days are recorded in Payment Details. Select the Payment Details Tab and enter the relevant details.

Pay Mode: Select the mode of payment from the list of payment modes catalogued.

Bank Code: Select the code of the bank on which the cheque is drawn.

Credit Days: Enter the credit period in terms of days offered to the stores.

Transit Days: Enter the number of days for the transporter to deliver the items to the stores.
