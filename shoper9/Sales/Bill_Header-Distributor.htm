Invoice Header

The header part of an invoice is displayed.

Select either Product or Service, as the type (configurable) of invoice.

Select Cash or Credit as the transaction type of the invoice.

The consecutive boxes display the Bill Doc Prefix (Document Prefix of the invoice) and the Bill Doc Number (Document Number of the invoice), as per your Bill Prefix settings. The invoice date and time are displayed by default and cannot be edited. The date displayed is the current Shoper date.

Customer: Enter customer code in the first box. Enter the customer name in the next box. Alternatively, press F2 and select the customer code from the Browse window (Customer Search window). If the customer code is selected from the Browse window, the customer name is displayed in the invoice. Customer selection is mandatory for invoicing.

During invoicing, the customer selection is possible only if:

  • The credit limit and credit days are defined for the selected customer in the Customer Catalogue

  • The fields Allow Cash Bill and Allow Credit Invoice have to be enabled for the selected customer

Note: In a distributor environment, the values set for the customer related parameters do not affect the customer selection during invoicing.

Sales Staff: Select the sales staff Id (configurable) from the list, if all the items to be invoiced are handled by the same sales person.

Recall: Click to recall the saved documents. The documents that can be recalled during invoicing are:

  • Sales Order

  • Sales DC

  • Approval Issue DC

  • Suspended Invoice
