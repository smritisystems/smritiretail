Returns with Invoice Reference

This option is used to carry out sales returns of merchandise invoiced earlier, only if the customer produces the invoice.

In an invoice, where items purchased under some promotional scheme (only in the case of offers) are to be returned, then all the items mentioned in the invoice need to be returned. For example, an item A with an offer "Buy two, get one free" when billed, is to be returned due to some reason. The customer had bought two Nos. of item A and had obtained one No. of item A free according to the offer. So while returning, the customer has to return all the three items.

The Return With Invoice Reference window is displayed.

Invoice Doc. Pfx.: Enter the Document Prefix of the invoice to be returned.

Invoice Doc. No.: Enter the Document Number of the invoice to be returned. If the invoice is available in the system and if it is not fully returned or voided earlier, the details of the invoice get displayed. Otherwise, an error message prompts the non-availability of the invoice for returning.

Return Entire Invoice?: Select this option, if the entire invoice (i.e., all the items in the invoice) is to be returned.

Reason Code: This field is activated only if the option, Return Entire Invoice? is selected. Select the reason for the return of the invoice, from the drop down list, if all the items of the invoice are returned for the same reason. If different items are returned for different reasons, then this field can be skipped and the reason for return can be recorded at the item level.

Bill Type: The invoice type (Product/ Service) and the transaction type (Cash/ Credit) of the invoice number entered are displayed.

Customer Code: The customer code of the invoice number entered is displayed.   

Customer Name: The customer name of the invoice number entered is displayed.

Return Reference

Prefix: The prefix set for invoice return gets displayed.

Doc. No.: The document number for the invoice return is generated automatically.

Item Details Grid

The item details of the document number selected for return get displayed in this grid.

For each item in the selected invoice, the following details are displayed.

The Stock No. and Item Description are displayed in the respective fields.

Billed: The total quantity of the item billed at the time of invoicing, is displayed.

Returned Qty.: If the invoice has already been subjected to one or more returns earlier, the quantity returned so far is displayed.

Cur. Returned Qty.: Enter the quantity of the item to be returned. If the entire invoice is returned, then the total quantity of the item is displayed, where quantity cannot be altered.

Reason: Select the reason for return of the item, from the drop down list.

Disc. Amt.: The discount amount of the item, if any, is displayed.

Tax Amt.: The tax amount of the item, if any, is displayed.

Net Amount: The net amount of the invoice is displayed.

Total Value: The net value of the items being returned is displayed in this field.

Return: To return the invoice. Click here to know how the Bill return value is handled.

Cancel: To cancel the entry
