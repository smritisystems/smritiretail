Item Search

Flexibility in browsing item details based on its attributes helps to avoid the time consuming manual search. Item Search enables you to identify the stock number of an item efficiently. There are two sets of selection criteria, namely, General Selection and Advanced Selection are available to make the item search more specific.

When you press F2 in Stock No field, the Advanced Item Search window is displayed.

General Selection: Enter the relevant values in the respective parameter fields for the required item search. The parameters come under General Selection are Stock No, Item Desc, Product, Brand, Style, Shade, Size and Quantity.

Note: In some of the fields related to the Item Classification, say, Product, you can press F2 again to list the catalogued values to select from.

The catalogued values for the Item Classification Product is displayed.

Search: Click this option to view the details of all the items matching the provided search criteria. Alternatively, press F4 or Alt+S to view the same details. Select the required item and press Enter.

A typical browse window is displayed.

Change Criteria: Press Alt+R or F3, to change the criteria used for any of the parameters, if required. For example, the parameter Quantity under General Selection, is provided with three criteria, namely; Greater Than, Is and Less Than. You can change to any of the criteria by pressing Alt+R or F3 when the cursor is placed in Quantity field.

The Advanced Item Search window, where the criteria selected is Quantity Is 10 is displayed.

Here, the items with Cur Bal Qty (current balance quantity) is 10 are displayed.

Image Preview Required: Select to display the image associated, optionally, with the item in the item master. This feature is used for cross verification of the item being invoiced and the item numbers displayed. This option may be used while dealing with high value items.

The Advanced Item Search window, where the image associated with the selected item is displayed.

Click on the image and the Image Viewer window is displayed. The Image Viewer window gives you the choices to Zoom In or Zoom Out the image.

Advanced: Click this option to display additional filter conditions using which the search can be further refined. Alternatively, press Alt+A to display the same additional filter conditions.

The Advanced Item Search window with Advanced Selection criteria is displayed.

Advanced Selection: The parameters come under Advanced Selection are Retail Price, Department, Buyer, Fibre, Finish, Colour Base, Styling, Usage and Service Item (for Service Invoicing).

Save Setting: To save the filter conditions last used. These filter conditions will be automatically displayed while using the browser again. This feature is useful when you use the same filter criteria repeatedly. In case you have to change the filter conditions, click on Clear, provide new conditions and click Search. For the next search, the last saved settings are available.

Clear: To clear the entered selection criteria.

Press Enter or double click on the item to be selected.

Note: In an item search, if you want the list of items obtained in the previous search, press Ctrl+Insert in the Advanced Item Search window.
