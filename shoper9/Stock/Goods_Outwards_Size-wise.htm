Goods Outwards Size-wise

Use this option to record goods issues/ returns through a size-grid for multiple sizes, for a given pair of style-article (SubClass1) and shade-variant (SubClass2). Check the box against this option in the Goods Outwards window to activate it.

The Size-wise Entry option helps with easily understandable user interface to:

  • Perform the outward activity in less time

  • Minimise the number of entries to be made

Goods outwards quantity for different sizes can be captured in a single line, based on the transaction type selected.

Note: LSQ parameter is not applicable to Goods Outwards Size-wise

 

 How to reach:  Stock > Goods Outwards

 

The Goods Outwards window is displayed. In this window you can execute the following functions.

Add: Click to record goods outwards entry. Click here for more information.

Edit: Click to correct or edit the existing entry. Click here for more information.

Delete: Click to remove an outwards document. Once the grid is populated, click Ok.

Reprint: Click to reprint an outwards document.

Exit: To quit the Goods Outwards Size-wise window.

 

Note: Both edit and delete can be done only for documents pertaining to the current Shoper date.
