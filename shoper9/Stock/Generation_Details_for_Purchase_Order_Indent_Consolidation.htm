Generation Details for Purchase Order/ Indent Consolidation

The Generation tab is as shown.

Purchase/Indent Document Details:

Type: Select the type from the list.

Prefix: Select the purchase order/ indent prefix from the list.

Number: The purchase order/ indent number is displayed. This is a running serial number.

Date: The current date is displayed as the date of purchase order/ indent.

Supplier: Choose the supplier to whom the purchase order/ indent is to be sent.

Bill To: Choose the location to which the bill has to be sent.

Delivery Date: Enter the expected date of delivery. Alternatively, you may enter the number of days (lead time) in which the supplier needs to fulfil the order.

Lead Time: The number of days that the supplier gets to fulfil the order from the date of purchase order generation is displayed, if you have entered the delivery date. Alternatively, enter the lead time in number of days.

Delivery Location: The delivery location will be Same location. (Changing delivery location is not allowed in distributor)

Picture: As you browse through the items in the grid, the image of the item will be displayed here, if available.

Configure: To open the Entry Column Selection.

Common Tax / Duty (%): Enter the tax/ duty as a percentage. The value entered here would be treated as the default tax percentage for all items. However, you can change the rate for individual items, if required.

The columns of the grid are based on the attributes used to identify the items at the POS location and the values are as per the indents/ POs selected. The attributes are arranged based on the order you specified in Configure. Other attributes that are displayed in the grid, irrespective of the selections, are Rate, Order Qty, Total Value, Tax/Duty, Net Value and Delivery Date. Make necessary changes in the values that are editable, if required.

Total:

Qty: Displays the total of all order quantities in the purchase order.

Gross Value: Displays the gross value of the purchase order.

Net Value: Displays the total net value after tax.

Next: To move to the Other Details tab

Clear: To undo all the changes you have made

 

F2: To browse the values to populate the current column. If the value for Subclass1 (Style) is entered and the user presses F2 when the cursor is on the stock number, then only those stock numbers of items with the selected style are displayed in the browse. In case you enter the starting characters of the field, all values starting with those characters are displayed in the browse window. You can also use the browse facility in any sequence, for example, you can first select the brand, then the stock number.

F4: To delete the current row.

F5: To enter quantity.

F6: To copy the previous row as is. This reduces the effort of re-typing all the values. Make necessary changes.

F7: To copy rate, order quantity, tax and delivery date specified in the previous row, after you enter the item specification.
