User Authorisation

With this option, you can add new users or modify the details of existing users. You cannot delete users once they have been defined. However, a user can be denied access to the system by setting the user weight to 0 (zero).

How to reach: Setup > Supervisory Functions > User Authorisation

The User Authorisation window is displayed to confirm the supervisor's login ID and password.

 

Super User ID: Enter supervisor’s login ID.

Password: Enter supervisor’s password.

Ok: To continue

Exit: To quit the process

On clicking Ok, the Add Authorization window is displayed.

User ID: Enter login ID. If an existing login ID is entered, the details of the login are displayed.

User Name: Enter a name if you are adding a new user. This name is used in greeting the user and referring to an ID.

Password: For existing users the password can be entered here to proceed.

Check this if you want to change your password: Click to change the password for an existing user.

New Password: Enter a password. This option is to change password for existing user or to set password for a new user. Once you enter a new password and press Enter, it reconfirms the password in the same field.

User Weight: Enter user weight for accessing Shoper 9 POS.

On pressing Tab, the window displays the grid with current company details.

Company Code & Name: Displays the company details defined in the system.

Login Name: The currently selected login name is displayed here.

Priority: Enter a number between 0 and 9999. Give priority for each company as per the requirement.

Save: To create the new user or modify the existing user parameters. The current company details are displayed in the grid.

Delete: To delete the selected user. You can delete a user by assigning zero weight to the user.

Cancel: To abort the authorisation process.

Exit: To close the screen.
