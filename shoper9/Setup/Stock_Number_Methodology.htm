Stock Number Methodology

This option is used when the user opts for the Shoper 9 generated stock numbers rather than allotting it manually. Various parameters that help in defining the stock number are to be provided. A stock number can be defined as a combination of a maximum of seven segments of digits, each of which can be of different but specified length optionally delimited with the required character.

How to reach: Setup > General > Stock Number Methodology

The Stock Number Generation Methodology window is displayed.

Note: Stock number methodology definition can be done only if there are no item masters.

Number of Segments: Select the number of segments that denotes the length of the stock number.

Note: The number of segment tabs (Seg 1 to Seg 7) enabled depends on your selection in Number of Segments.

Segments Are

Delimited: Select if the segments are separated by a delimiter.

Fixed: Select if the segments are of fixed length.

Delimiting Character: Enter the delimiter, which can be a comma, full stop or hyphen.

Seg 1

Number of Digits: Enter the length of the segment under consideration.

Type of Segment: Select the type of the segment from the drop down list. The choices available are Auto incremented, User Assigned and Derived.

Note: There can be only one auto increment segment and if present, it should be the last segment.

Field Derived From: Select the source, for e.g., Class1, Class2, SubClass1, SubClass2 or SizePackUOM, if the segment type is Derived. This field is not enabled, if the segment type selected is either Auto incremented or User Assigned.

Starting Digit of the Field: Enter the starting digit of the field mentioned in Field Derived From, if the segment type is Derived.

Suppose if the stock number is generated with respect to segment-1, where the length of the segment is three, derived from the field Product and the starting digit is 01. The details entered in the window is displayed.

Ok: To save the definition.

Cancel: To exit Stock Number Generation Methodology window.

 

Caution Message: In case you have defined a stock number methodology already or opt for the user assigned stock number and created item masters, then this option cannot be accessed. Shoper 9 displays a message of caution as shown.
