Userwise Menu Restrictions

The Menu Restriction for User window is displayed.

 User Name: Select the user name for which access rights have to be managed.

Ok: To continue assigning permissions for the selected user

Cancel: To quit the application security restrictions process

The Menu Restriction for User window is displayed.

Copy From: Select the user name whose access permissions may be copied and click Copy. This option is useful when you want to give the same permissions as that of an existing user or most of the permissions are the same. After copying permissions from another user, you can make required changes.

The menu tree is displayed. The options that can be currently accessed by the selected user is checked while the inaccessible items are unchecked.

Expand All: Click to expand the tree structure.

Collapse All: Click to collapse the tree structure.

Right click the menu option in the tree structure to display a pop-up with access permissions for the current sub-option. Check or uncheck the required permissions listed in the pop-up.

Save: To save the changes made to application security restrictions of the selected user. If you want to modify access permissions for another user select the user name and continue, else click Cancel. If you want to modify access permissions for a node select the same and click Next, else click .

Cancel: To quit the application security restrictions process.
