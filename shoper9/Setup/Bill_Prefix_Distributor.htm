Bill Prefix

The bill prefix definition is a process where various prefixes and the starting document number to be used for Cash Invoice, Credit Invoice and Void Invoice under a Product and Service Invoice are defined.

How to reach: Setup > General > Bill Prefix

The Billing Transaction Prefixes and Starting Doc Numbers window is displayed.

 

Note: If invoicing option is tried without carrying out this option you will get appropriate message.

Node ID: Displays as entered at the time of installation or by using Node Management option. This cannot be revised here.

Note: Same prefixes across multiple terminals can be set. This functionality can be activated by selecting system parameter Common Prefix used Across All Terminals for Bill serialization under the category Billing.

Year Suffix: Displays by default and gets appended to the prefixes to be entered.

Cash Transaction: Enter relevant prefixes and document numbers for Sales, Return (Sales Return) and Void Sales (Sales cancellation) of Product and Service.

Prefix: Type a meaningful prefix to suggest the transaction referred by it.

Doc. No.: Enter the number from where the numbering for the concerned transactions begins.

Same For All Void Transaction: Select this option to define same prefixes for Void Sales in Cash and Credit Transactions.

Credit Transaction: Enter relevant prefixes and document numbers as in the case of Cash Transaction.

Note: The prefix for Void Sales in Credit Transaction cannot be altered, if Same For All Void Transaction is selected.

  Click the relevant button to select the required set of prefixes.

Note: If the Shoper 9 application is configured for common prefix, then you need not run the bill prefix definition from each node.

 

New: To enter another set of different prefixes and document numbers. This button is activated only after you enter one set of all the prefixes.

Ok: To save the record.

Exit: To quit the operation.
