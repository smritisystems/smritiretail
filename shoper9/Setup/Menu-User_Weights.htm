The Menu-Weightage-Form is displayed. All existing menu options are displayed in the grid with the currently assigned weights. The default weight assigned to all options is zero.

Change menu weights wherever required. Menu weight can be a number in the range 0 through 9999.

After changing the required values, click to close the window.

The User Weightage Form is displayed.

All the user names are displayed in the grid with the currently assigned weights. The user weight for the super user is displayed in red and is 9999. Change user weights wherever required. User weight can be a number in the range 0 through 9999.

After changing the required values, click to close the window.

Menu/ User Weights

Menu and user weights are used to ensure security to Shoper database. This option allows the defining of weights for menu options and users.

How to reach: Setup > Supervisory Functions > Menu / User Weights

The Weightage Option Form is displayed as shown.

 

Define Weightage for: Choose A Menu or A User for which the weight is to be defined.

Next: To move to the next step

The Weightage Option Form extends to display the Authentication Required details.

 

Super User Name: Enter supervisor’s login ID.

Password: Enter supervisor’s password.

Login: To login and assign user weight

Cancel: To quit the process

If the user name and password are correct, the next window will be displayed depending on your choice:

  • A Menu

  • A User

Note: Ensure that the Menu Weights are equal or lesser than the User Weights
