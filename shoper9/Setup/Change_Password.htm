Change Password

You can change your password after logging in. A Super User can change the password for any user.

How to reach: Setup > Supervisory Functions > Change Password

The Change User Password window is displayed.

 

User ID: Enter the User ID for which the password has to be changed.

Note: To change the password of a user other than the currently logged in user, you should have supervisory rights.

User Name: The name corresponding to the ID is displayed.

Old Password: Enter the current password of the specified login ID.

New Password: Enter the new password for the specified login ID. On pressing Tab or clicking Ok, the value entered in New Password gets cleared and a message Retype the Password is displayed on the status bar. Re-enter the new password for confirmation. If retyped password does not match the earlier entry, a message Incorrect Password is displayed.

Ok: To save the changes in the password and exit from the option

Cancel: To exit from the option
