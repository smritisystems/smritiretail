Nodewise Menu Restrictions

The Menu Restriction for Node window is displayed.

Node Id: Select the node id for which access rights have to be managed.

Ok: To continue assigning permissions for the selected node

Cancel: To quit the application security restrictions process

The Menu Restriction for Node window is displayed.

 Copy From: Select the node id from which access permissions may be copied. This option is useful when you want to give the same permissions as that of an existing node or most of the permissions are the same. After copying permissions from another node, you can make required changes.

The menu tree is displayed as shown. The options that can be currently accessed by the selected user is checked while the inaccessible items are unchecked.

Expand All: Click to expand the tree structure.

Collapse All: Click to collapse the tree structure.

Right click the menu option in the tree structure to display a pop-up with access permissions for the sub-options. Check or uncheck the required permissions listed in the pop-up.

Save: To save the changes made to application security restrictions of the selected node. If you want to modify access permissions for another node select the node id and continue, else click Cancel. If you want to modify access permissions for a user select the same and click Next, else click .

Cancel: To quit the application security restrictions process.
