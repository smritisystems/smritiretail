Menu / Node Restriction

The users or nodes can be given access to the relevant options and the rest can be disallowed on a case to case basis. This option is used for the same.

How to reach: Setup > Supervisory Functions > Menu / Node Restriction

The Menu Restriction window is displayed as shown.

Restrictions for: Choose A User or A Node / System in the network.

Next: To accept the super user login details

The Menu Restrictions for User window is displayed.

Super User Name: Enter supervisor’s login ID.

Password: Enter supervisor’s password.

Login: To login and assign permissions

Cancel: To quit the process

If you have chosen A User, click here to learn more and if you have chosen A Node/System in the network, click here.
